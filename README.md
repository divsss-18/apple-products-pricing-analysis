# 🍎 Apple Products Pricing Analysis

A data analytics project analyzing Apple product **pricing, ratings, reviews, categories, and marketplace trends** across Amazon and Flipkart.

## 🔍 What I Did
- Cleaned and explored the dataset using Python
- Performed analysis using SQL
- Created an interactive Power BI dashboard
- Compared pricing, ratings, reviews, and platforms

## 🛠️ Tools
Python • Pandas • NumPy • SQL • Excel • Power BI

## 📊 Dataset
80,000 Apple product records from 2020–2026.
